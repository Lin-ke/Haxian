# 简介
**哈闲**（Haxian）是由***Hiters***研发的一款同校二手交易平台。我们将哈闲集成到「哈工大」APP信息矩阵，搭建信息中台，以既有需求为抓手，完成用户间短平快、端到端的资源置换。在哈闲，同校师生可以出售自己的闲置物品，也可以发布求购，共建智慧校园，共享绿色生活。


# 使用手册
用户在哈工大APP中点击哈闲图标进入二手交易平台。进入平台页后，在底部导航栏中能看到四个图标和“+”加号键，由左至右分别对应五个页面：**浏览出二手帖子；浏览收二手帖子；发布帖子；查看消息中心；个人中心**。

在详情页面，用户能看到帖子内容。在帖子图文下方是若干帖主想出物品的**物品卡片**，包括名称、标价和该物品的简介。在右上方是收藏按钮，用户可以点击以收藏帖子，并在“个人中心-我的收藏”看到收藏。


若对帖子中的内容感兴趣，用户可以发起回复。
点击加号，开始对帖子回复。特别是，我们期望用户勾选感兴趣的物品，并记录自己的出价。

对帖主而言，在进入帖子详情页后，可以在**物品卡片**中看到对应物品想要的人和价格。用户可以选择出价较高的买者，并与其交流。滑动到下方，能够看到若干条回复。

## 发帖
通过点击导航栏的“+”进入发帖界面。用户需要填入标题、理想的交易地址和帖子内容，并根据需求用标题栏旁的开关选择“想出物品”或“想收物品”。用户可以点击“+”上传图片。

用户还可以点击下方的“+”，以添加物品卡片。每个物品分类为“书籍”，“生活用品”，“电子产品”及“其他”几类。

## 个人中心
通过点击导航栏的  进入个人中心界面。在这个界面中，用户可以维护自己的个人信息，并查看已经收藏的贴子。点击“个人信息”，能看到用户的一些资料，用户可以编辑，以便在发帖过程中快捷填写。点击“我的收藏”，能看到用户收藏的帖子。用户可以编辑收藏。
